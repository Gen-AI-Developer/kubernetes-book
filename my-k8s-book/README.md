# Kubernetes for Absolute Beginners: Developing Cloud Applications

This repository contains the source code for the "Kubernetes for Absolute Beginners" textbook, built with Docusaurus.

## Overview

This textbook is designed for absolute beginners with no prior Kubernetes or container experience. It covers the fundamentals of Kubernetes in a clear, accessible way, with practical examples and exercises.

## Features

- 6 comprehensive chapters covering Kubernetes fundamentals
- Interactive code examples with syntax highlighting
- Mermaid diagrams for visualizing concepts
- Responsive design for all device sizes
- Dark mode support
- Multi-language support (English and Urdu)
- Built-in search functionality
- Quiz components for self-assessment

## Chapters

1. History of Cloud Native Applications
2. What, Why, Need, and How of Kubernetes
3. Setting Up Your First Kubernetes Environment
4. Core Kubernetes Concepts: Pods, Deployments, and Services
5. Developing and Deploying Cloud-Native Apps
6. Best Practices and Scaling

## Development

### Installation

```bash
npm install
```

### Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

### Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static hosting service.

### Deployment

The site is configured for deployment to GitHub Pages. Use the following command:

```bash
npm run deploy
```
